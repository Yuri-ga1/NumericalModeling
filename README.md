# How to use ssh key with github?

Сгенерировать ключ:
```
ssh-keygen -t ed25519 -C "your_email@example.com"
```

Стандартный путь до файла с ключем. Если вы на прошлом этапе дали другое название, то его надо поменять.
Выведите ключ или можете просто открыть файл в текстовом редакторе и скопируйте его:

```
cat ~/.ssh/id_ed25519.pub
```

Так же для автоматического подтягивания ключа при выполнении команд git можно создать файл __config__ с следующим содержимым:

```
Host github.com
HostName github.com
User git
IdentityFile {Ваш путь до файла}
```

1. Перейдите на сайт GitHub и войдите в свой аккаунт.
2. В правом верхнем углу кликните на свой аватар и выберите Settings (Настройки).
3. В левом боковом меню перейдите в раздел SSH and GPG keys.
4. Нажмите кнопку New SSH key (Добавить новый ключ).
5. В поле Title введите понятное название для компьютера (например, «Рабочий ноутбук»).
6. В поле Key вставьте скопированный ранее текст ключа.
7. Нажмите Add SSH key. При необходимости подтвердите действие паролем от аккаунта GitHub.

После вы можете скопировать свой репозиторий при помощи:

```
git clone git@github.com:{имя_пользователя}/{Название_репозитория}.git
```
